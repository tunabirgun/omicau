Start with your data.

Use the bundled synthetic example first, then define an endpoint and the assays you want to compare.

Command line

Download the Python wheel from the v0.6.0 release. With Python 3.10 or later installed, run these commands from the directory containing the wheel.

python -m pip install ./omicau-0.6.0-py3-none-any.whl
omicau check-env
omicau bootstrap --dataset mock --out-dir demo
omicau run --config demo/config.json --cores 8
omicau verify --config demo/config.json --audit demo/run/audit.json

Open demo/run/report.html when the run finishes. Choose a core count that fits your available memory and workload.

Desktop bundles for Windows, Linux and macOS are also listed on the release page.

Local browser interface

For guided input selection, download and extract the software source from the release page. From that source directory, install the optional interface and launch it:

python -m pip install ".[ui]"
omicau ui

Open the local address printed in the terminal. The browser uses the same analysis pipeline and exposes a subset of its configuration options. Keep the terminal running while using the interface.

Prepare your inputs

Provide one numeric CSV or TSV matrix per assay and a clinical table containing the outcome. Omicau aligns the samples across those inputs.

InputWhat it supplies
Assay matricesNumeric features for each molecular layer.
Clinical tableSample identifiers, endpoint, and available group and batch columns.
ConfigurationInput paths, outcome definition, model settings and output directory.

Use the outermost independent source as the group: for example, keep repeated observations from one participant together. Include a batch variable when it is available.

See the configuration example

Follow the run

The workflow aligns inputs and records sample availability, missingness and group structure. Learned preprocessing is fitted in training data, and models are evaluated on shared partitions that respect the declared groups.

Single-assay, full-fusion and omitted-assay reference models provide complementary views of prediction. Inspect their scores together with the paired layer results and diagnostics.
